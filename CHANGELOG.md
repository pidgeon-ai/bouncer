# Changelog

## 0.2.0 (26 October 2026)

Bouncer is now an example you run yourself on your own Pidgeon account, for one owner; there is no hosted service. Asks first by default (style 3): nothing goes to a stranger until you reply YES. Removed multi-user sign-up, per-user pods and the public website; added a self-host quickstart and a "Build your own email agent" guide.

## 0.1.0 (24 October 2026)

First version: a multi-user design meant to be hosted, never launched. Tagged `v0.1.0`.
